# 节点归属与保守命名（2026-11-17）

用户在 [生产审核](NAMING_AUDIT_2026_11_17.md) 后要求直接修复。新增迁移 `0023_identity_naming`，保留 GeoLite、Echo、ip-api 原始证据，不用多数票改写地理库，也不推断物理中转。

## 展示和命名

- 唯一入口解析 IP 与已观测出口 IP 相同：目录 `entry_country`、名称、筛选与报表统一采用落地国家，避免不同数据库给同一个 IP 不同国家时生成虚假的跨国箭头。原入口国家保留在状态表及详情 `identity.raw_entry_country`。同 IP 不证明同机房；多 IP 入口不做这种归并。
- 入口国家未知而出口国家已知：`?->SG`。两端国家已知且相同仍为 `SG`。国旗仍代表落地国家。
- `{OPERATOR}` 仍是落地 IP 的 org 简称与落地 ASN 简称，不是入口运营商与落地运营商。org、ISP、AS 组织原文在详情分开显示。
- ASN 别名优先用户设置和内置表；本次依据公开 ASN/RIR 证据增加 Contabo AS141995、Psychz AS40676、GTT AS3257、Lumen AS3356、BAGE AS63150，不覆盖 USER。`Private Customer`、`Unknown` 等精确占位文本不能生成品牌，缺乏有效简称时回退 `AS<number>`。其余首词缩写仍为启发式，不宣称所有 ASN 品牌均已认证。
- ip-api AS 组织只能补充同一个数值 ASN，不跨 ASN 借用。Echo 组织也只与其自己的 ASN 配对；缺 Echo ASN 时使用匹配的 GeoLite 组织。
- 序号仍按落地 IP 和归属组维护，组不变时保留。已修正品牌导致归属组改变时可能重新编号；节点 ID、短编号、配置指纹、订阅 token 不变。自定义模板保留，订阅成品失效后由 Actions 重新生成。

## 新鲜度和混用防护

`node_current_status.exit_observed_at` 仅在成功检测实际拿到出口 IP 时更新。迁移从保留的、同节点同 IP 的成功检测明细回填最近时间；没有证据则留空，不使用会被备用检测刷新的 `last_success_at` 冒充出口时间。

备用地址确认连通时保留旧落地，但显示“历史落地”与最后观测时间。新 IP 出现时不继承旧 IP 的国家、ASN、组织；同 IP 的 ASN 变化也不继承旧 ASN 组织。同 IP 缺字段仍保留已知信息。

前端表头改为“入口 / 落地”，提示这些是 IP 数据库归属。详情展示 GeoLite 原入口、出口来源、各库国家/ASN 分歧、ip-api 查询时间及出口观测时间。旧记录未区分 Echo/GeoLite 时如实说明，不伪造来源。

## API 与成本

完整节点投影新增 `identity`、`identity_flags`、`exit_observed_at`；精简投影只在末尾追加后两项，继续以 `fields` 映射位置，避免为整个列表重复输出来源 JSON。

| identity_flags 位 | 含义 |
| --- | --- |
| 1 | 唯一入口 IP 等于保存出口 IP |
| 2 | 国家来源有分歧 |
| 4 | ASN 来源有分歧 |
| 8 | 有保存出口，但本轮没有重新确认或最后观测时间未知 |
| 16 | 展示入口国家未知 |

无新增外部服务、付费项目或逐 ASN 在线请求。使用现有缓存和已核实的静态别名。
